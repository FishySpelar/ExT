DO NOT DOWNLOAD, EXECUTE, OR RUN THIS APPLICATION ON YOUR PERSONAL OR WORK DEVICE.


ExT is an experimental system-information collection project developed for educational and research purposes.


What does ExT collect?


When executed, the application may collect and transmit the following information to a remote server:

Computer name and Windows username
Operating system and Windows edition
CPU model and system architecture
IP address
Commercial Enterprise Connections
Home, user, temporary, and system directories
Domain and computer domain information
Runtime information, including process IDs and Python paths
System language, timezone, and local date/time

Information collected by ExT may contain personally identifiable or sensitive system details.
